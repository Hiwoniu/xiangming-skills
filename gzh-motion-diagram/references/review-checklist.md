# 人工复核清单

**必须用看图工具实际打开这三张图**，再逐条判定：

1. `_review/snapshots/contact-sheet*.jpg`：关键帧（每个场景的中段 + 切场前定格帧；帧多时会分成 -1、-2 两张，都要看）
2. `_review/gif-sheet.png`：GIF 成品抽帧（看转码后的颜色、锯齿、色带）
3. `_review/phone-sheet.png`：缩到 375px 宽的效果（看手机上读不读得清）

判定只有 ✓ / ✗ 两种，没有"基本可以"。拿不准一律判 ✗，然后去修。

## 复核项

| # | 检查项 | 看哪张 |
|---|---|---|
| V1 | 没有任何文字被截断、溢出容器，或被别的元素意外遮挡（有意的堆叠要在例外里说明） | 1 |
| V2 | 没有元素贴边或出界；舞台元素和标题区、结论条之间有明显间距 | 1 |
| V3 | 每个场景的定格帧单独拿出来也能看懂（E4） | 1 |
| V4 | 概念颜色、元件和 design-system 第 4 节一致；accent 只给一个主角用（C7/C8） | 1 |
| V5 | 画面中的每个数字、术语，都能在 storyboard.md 里找到对应的原文行号（E1/E2） | 1 + storyboard |
| V6 | GIF 里没有明显色带、杂色或文字发虚 | 2 |
| V7 | 手机宽度下标题、chip、元件名都能看清；最小的字也认得出是什么字 | 3 |
| V8 | 切场时没有空白帧、闪烁，也没有上一幕残留 | 1（切场附近）|
| V9 | 同一时刻最多 2 处在动；结论条在切场前 ≥ 2.5 秒出现；运动路径不互相穿过（D4/D5/R5b） | 逐场景回看 MP4 或连续帧 |
| V10 | `_review/check.log` 里每条 warning 都按 hard-rules D6 处理（自动豁免 / 已修复 / 有意为之 + 理由） | check.log |
